# asset/ 이미지 폴더

```
asset/products/P0001.jpg   상품 대표 이미지 (파일명 = products.json의 product_id)
```

- 이미지를 넣은 뒤 `js/data.js`의 `const IMG_ON = false;`를 `true`로 바꾸면 화면에 나타납니다(파일이 없는 상품은 "이미지" 자리표시 그대로).
- 권장: 가로 600px 안팎, 장당 100KB 이하 (`loading="lazy"`로 필요할 때만 불러옴).
- **출처 규칙**: 가상 상품에 실제 브랜드의 상품 사진을 쓰지 않습니다. 직접 촬영·직접 제작·라이선스가 허용된 무료 이미지만 쓰고, 출처를 `docs/SOURCES.md`에 적습니다.
- 브랜드 로고(상표)는 사용하지 않고 텍스트 이니셜로 표시합니다.
