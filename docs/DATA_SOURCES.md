## 2. 연결 방식
- **저장 JSON** (외부 API 미연동). `js/data.js`의 `loadAll()`이 4개 파일을 `fetch`로 읽는다. 저장 JSON 로딩 위치는 이곳 한 곳뿐이다.
- API 요청과 API 실패 시 대체 데이터는 사용하지 않는다.
- 갱신 시점: 팀이 JSON을 수정·푸시할 때(수동).
- 불러오기에 실패하면 오류 화면과 "다시 시도" 버튼을 보여준다.

## 4. 한계와 화면 안내
- **브랜드별 사이즈 경향(크게/작게 나옴)은 검증되지 않은 가정값**이다(`tools/generate_data.py`의 `BRAND_BIAS`). 실제 브랜드 특성이 아니며, 화면의 "정사이즈 후기 %", "크게 나오는 편" 등은 이 더미 후기에서 계산한 값이다.
- 더미 체형은 키·몸무게를 정규분포(키 평균 약 160cm·BMI 평균 약 21.6)로 만들고, 나머지 치수는 앱 `bodyOf()` 추정식 + 임의 편차로 만들었다. 공식 인체치수조사(Size Korea) 원자료로 보정하지 않았다.
- 사이즈 추천 "정확도"를 주장할 수 없다. 더미 후기는 규칙(`tools/fit_model.py`)으로 생성했으므로 규칙과 일치하는 것이 당연하다.
- 실제 후기는 1건뿐이다. 날짜가 없고 부위별 판정이 없다.
- 화면 안내 문구: 브랜드 상세 상단 "상품·후기·체형 데이터는 실습용 더미 데이터예요(실제 후기 1건 포함). 브랜드별 사이즈 경향은 검증되지 않은 가정값이에요." + 목록 카드의 "저장 JSON" 칩과 더미 값의 점선 테두리, 상세 각 행 옆 실제/더미/미확인 태그.
